# «Жизнь подростка» — патч v5.1.1

v5.1.1 исправляет загрузку папки `files` из GitHub: теперь в ней все 445 файлов, включая изображения, шрифты и видео. Файлы поставки сохраняются Git без преобразования переводов строк на Windows. При проверке текстовых файлов допускается только разница LF/CRLF; содержимое и бинарные файлы по-прежнему проверяются по SHA-256.

Для файлового менеджера хостинга удобнее архив `lifepodrostka-netcat-v5.1.1-upload.zip`: внутри сразу `zhp-install.php` и `netcat_template`, без внешней папки `UPLOAD_TO_ROOT`. Его можно загрузить и распаковать прямо в корне сайта с заменой файлов.

v5.1 исправляет подтверждённые при проверке свежих бэкапов ошибки отката
на MySQL 5.7, зависимости контактов от отсутствующего виджета `regions`
и открытия одного окна консультации как галереи Fancybox.

Новый журнал хостинга установил непосредственную причину остановки:
`Too many open files` — процесс PHP не смог открыть файл ядра из-за
исчерпания файловых дескрипторов. Почему они закончились именно на хостинге,
пока неизвестно. Разница PHP 8.3.36 старого стенда и PHP 7.4.33 хостинга
сама по себе этого не объясняет. Порядок продолжения без удаления снимка —
[`docs/TOO_MANY_OPEN_FILES_RU.md`](docs/TOO_MANY_OPEN_FILES_RU.md).
Подробности проверки — `TEST_REPORT_RU.md`; старые отчёты v5 не являются
проверкой v5.1.

Патч заменяет прежний перенос заполненными страницами из присланной вёрстки.
Разделы без отдельного HTML созданы пустыми черновиками, без текстов,
инфоблоков и скопированного содержимого услуг. Они отключены в публичном
меню. Список назначений — `docs/SECTIONS_AND_LAYOUTS_RU.md`.

## Установка через браузер на shared-хостинге

1. Сохраните обычную резервную копию файлов и БД в панели хостинга.
2. Загрузите **`lifepodrostka-netcat-v5.1.1-upload.zip`** в корень сайта рядом с `vars.inc.php` и распакуйте там **с заменой файлов**. Затем удалите загруженный ZIP. Альтернатива: загрузите полную папку `files` из GitHub либо содержимое `UPLOAD_TO_ROOT` из полного архива — все 445 файлов, включая скрытые `.install` и `.htaccess`.
3. Войдите администратором в Netcat на том же домене.
4. Откройте `https://dev.lifepodrostka.ru/zhp-install.php`.
5. Убедитесь, что указана версия **v5.1.1**. Нажмите «Проверить файлы», затем «Установить / продолжить».
   Дождитесь завершения полной резервной копии и подготовки сайта.
6. Нажмите **«Включить и очистить прежний сайт»**, дождитесь завершения,
   затем нажмите «Проверить установку».
7. Проверьте сайт и удалите с хостинга `zhp-install.php`.

SSH, Composer и импорт SQL вручную не требуются. Все операции выполняются
короткими возобновляемыми запросами. Оставьте страницу открытой до окончания
шага. Если запрос остановился, повторите тот же шаг.

Если обработчик Apache не позволяет продолжить, доступен проверенный запуск
существующего установщика через локальный PHP CLI из cron в панели хостинга:
[`docs/CRON_INSTALL_RU.md`](docs/CRON_INSTALL_RU.md).

Патч рассчитан на приложенную базу Netcat 7.2.0 с одним сайтом №1 и исходными
регионами: компонент №223 / инфоблок №57. Сценарии после v4 и отката v3
проверялись исторически для v5; новая проверка описана в отчёте. Новая установка не переиспользует старые
компоненты переноса и не сохраняет их наполнение в рабочем дереве.

## Что удаляется

После резервного копирования из CMS удаляются прежние инфоблоки и разделы
сайта, макеты Medelta и предыдущих переносов, компоненты групп Medelta и
старые `lp_*` / `zhp_*`. Старые «Цены», «Кейсы», sitemap и архивы прежнего
сайта не остаются в дереве. Их файлы и данные сохраняются только в полной
резервной копии установщика. Служебные библиотеки и макеты самой CMS остаются.

Существующий региональный компонент №223, инфоблок №57 и записи регионов
сохраняются. Справочник переносится в группу «Регионы» без создания новой
региональной таблицы. Недостающие публичные поля добавляются.

В свежей базе `main_domain` существующей региональной записи равен
`medelta.clinic`, а домен сайта — `dev.lifepodrostka.ru`. Установщик предупреждает
об этом и не переписывает доменную привязку. Для вывода контактов на нужном
домене откройте существующую запись инфоблока №57 и укажите этот домен в поле
`main_domain`. Самостоятельно проверьте контакты и реквизиты перед публикацией.
Отдельный виджет `regions` теперь не требуется; новый справочник не создаётся.

Новые файлы находятся в `netcat_template/template/life_teen`, что позволяет
сначала сохранить старые файлы и лишь потом удалить прежние макеты.
Резервная копия хранится в `netcat_files/life_teen_v5/snapshot`. Не удаляйте
эту папку. На время установки не редактируйте сайт в другой вкладке.

В свежем бэкапе осталось незавершённое резервирование v5. До создания объектов
v5.1 сохранит такой снимок и его состояние в закрытом подкаталоге
`netcat_files/life_teen_v5/previous-incomplete-*`, затем снимет текущую базу и
файлы заново. Продолжение внутри v5.1 по-прежнему возобновляется с последнего
записанного шага. Завершённый снимок установленного сайта не заменяется новым.
Новые снимки сохраняют значения времени в UTC и фиксируют этот режим в манифесте.

Кнопка «Откатить изменения» восстанавливает базу и файлы на момент начала
установки v5. Повторная установка после такого отката проверена. Новые данные,
поступившие после установки, не входят в исходный снимок.

## Если ошибка загрузки PHP повторится

Установщик записывает предупреждения `require`/`include`, фатальную ошибку,
версию и режим PHP, ограничения памяти, пути и стек без аргументов в
`netcat_files/life_teen_v5/diagnostics.php`. Скачайте этот файл через файловый
менеджер хостинга или FileZilla и передайте для анализа. Пароли, параметры
запроса, cookie и содержимое базы в журнал не записываются. По HTTP файл
отдаёт 404; права файла — 0600, размер ограничен.

Журнал не отменяет проверок и не подавляет остановку. Если хостинг принудительно
завершил процесс без выполнения обработчиков PHP, потребуется журнал хостинга.

## Устройство и заполнение

- В общем макете — шапка, подвал, явные массивы `$mobile_menu` / `$h_menu`,
  настройки сайта и подключения скриптов. Используется способ Medelta,
  классы меню взяты из новой вёрстки.
- Дочерние макеты используют `%Header` / `%Footer`. Всего восемь макетов
  проекта; нет лишних обёрток `zhp-layout` и поясняющих комментариев.
- «ПОЗНАКОМЬТЕСЬ С НАМИ БЛИЖЕ»: префикс открывает `section` / `wrap`,
  объект содержит данные видео, суффикс закрывает контейнеры. Четыре поля.
- Общие постоянные блоки находятся целиком в префиксе без объектов.
  Окно консультации взято из `popup.html`, отправляет штатную форму Netcat.
- Статьи и специалисты заполняются один раз. Списки, слайдеры, команда,
  рекомендации и подробные страницы используют одни записи.
- Контакты, соцсети, MAX, часы и карта берутся из существующих регионов.
  Проверьте заполнение необходимых полей своего домена, в том числе `licinfo`
  для реквизитов. Год в подвале берётся из текущей даты PHP.
- Текстовый блок главной заполнен материалом из исходной статьи, без
  типографических надписей «Заголовок h1» и аналогичных примеров.
- Пустые разделы можно заполнить через инфоблоки, открыть доступ посетителям
  и включить в меню. Для каждого указан предполагаемый исходный HTML.

Заявки и подписки сохраняются в Netcat. Доставка писем по умолчанию отключена;
её параметры находятся в регионе. Перед рабочим запуском проверьте реквизиты
и юридические тексты и снимите настройку `noindex` общего макета.
