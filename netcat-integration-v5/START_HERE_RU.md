# «Жизнь подростка» — чистый патч v5

Патч заменяет прежний перенос заполненными страницами из присланной вёрстки.
Разделы без отдельного HTML созданы пустыми черновиками, без текстов,
инфоблоков и скопированного содержимого услуг. Они отключены в публичном
меню. Список назначений — `docs/SECTIONS_AND_LAYOUTS_RU.md`.

## Установка через браузер на shared-хостинге

1. Сохраните обычную резервную копию файлов и БД в панели хостинга.
2. Загрузите **содержимое `UPLOAD_TO_ROOT`** в корень сайта рядом с `vars.inc.php`.
3. Войдите администратором в Netcat на том же домене.
4. Откройте `https://dev.lifepodrostka.ru/zhp-install.php`.
5. Нажмите «Проверить файлы», затем «Установить / продолжить».
   Дождитесь завершения полной резервной копии и подготовки сайта.
6. Нажмите **«Включить и очистить прежний сайт»**, дождитесь завершения,
   затем нажмите «Проверить установку».
7. Проверьте сайт и удалите с хостинга `zhp-install.php`.

SSH, Composer и импорт SQL вручную не требуются. Все операции выполняются
короткими возобновляемыми запросами. Оставьте страницу открытой до окончания
шага. Если запрос остановился, повторите тот же шаг.

Патч рассчитан на приложенную базу Netcat 7.2.0 с одним сайтом №1 и исходными
регионами: компонент №223 / инфоблок №57. Работает с исходным сайтом, после
v4 и после штатного отката v3. Новая установка не переиспользует старые
компоненты переноса и не сохраняет их наполнение в рабочем дереве.

## Что удаляется

После резервного копирования из CMS удаляются прежние инфоблоки и разделы
сайта, макеты Medelta и предыдущих переносов, компоненты групп Medelta и
старые `lp_*` / `zhp_*`. Старые «Цены», «Кейсы», sitemap и архивы прежнего
сайта не остаются в дереве. Их файлы и данные сохраняются только в полной
резервной копии установщика. Служебные библиотеки и макеты самой CMS остаются.

Существующий региональный компонент №223, инфоблок №57 и записи регионов
сохраняются. Справочник переносится в группу «Регионы» без создания новой
региональной таблицы. Недостающие публичные поля добавляются.

Новые файлы находятся в `netcat_template/template/life_teen`, что позволяет
сначала сохранить старые файлы и лишь потом удалить прежние макеты.
Резервная копия хранится в `netcat_files/life_teen_v5/snapshot`. Не удаляйте
эту папку. На время установки не редактируйте сайт в другой вкладке.

Кнопка «Откатить изменения» восстанавливает базу и файлы на момент начала
установки v5. Повторная установка после такого отката проверена. Новые данные,
поступившие после установки, не входят в исходный снимок.

## Устройство и заполнение

- В общем макете — шапка, подвал, явные массивы `$mobile_menu` / `$h_menu`,
  настройки сайта и подключения скриптов. Используется способ Medelta,
  классы меню взяты из новой вёрстки.
- Дочерние макеты используют `%Header` / `%Footer`. Всего восемь макетов
  проекта; нет лишних обёрток `zhp-layout` и поясняющих комментариев.
- «ПОЗНАКОМЬТЕСЬ С НАМИ БЛИЖЕ»: префикс открывает `section` / `wrap`,
  объект содержит данные видео, суффикс закрывает контейнеры. Четыре поля.
- Общие постоянные блоки находятся целиком в префиксе без объектов.
  Окно консультации взято из `popup.html`, отправляет штатную форму Netcat.
- Статьи и специалисты заполняются один раз. Списки, слайдеры, команда,
  рекомендации и подробные страницы используют одни записи.
- Контакты, соцсети, MAX, часы и карта берутся из существующих регионов.
  Проверьте заполнение необходимых полей своего домена, в том числе `licinfo`
  для реквизитов. Год в подвале берётся из текущей даты PHP.
- Текстовый блок главной заполнен материалом из исходной статьи, без
  типографических надписей «Заголовок h1» и аналогичных примеров.
- Пустые разделы можно заполнить через инфоблоки, открыть доступ посетителям
  и включить в меню. Для каждого указан предполагаемый исходный HTML.

Заявки и подписки сохраняются в Netcat. Доставка писем по умолчанию отключена;
её параметры находятся в регионе. Перед рабочим запуском проверьте реквизиты
и юридические тексты и снимите настройку `noindex` общего макета.

## Проверочные адреса

- `/` — главная
- `/o-nas/` — о проекте
- `/podrostkam/trevoga-i-perezhivaniya/` — готовая страница услуги
- `/blog/` — статьи
- `/blog/kak-spravlyatsya-s-trevogoy-pered-ekzamenami.html` — статья
- `/o-nas/spetsialisty/` — специалисты
- `/o-nas/spetsialisty/golub-irina-aleksandrovna.html` — специалист
- `/o-nas/foto/` — галерея
- `/kontakty/` — контакты

Ссылки из общих блоков на ещё не заполненные «Подросткам», «Родителям» и
«Специалистам» пока ведут на готовую услугу или соответствующий фильтр блога.
Новые самостоятельные материалы для черновиков не сочинялись.
