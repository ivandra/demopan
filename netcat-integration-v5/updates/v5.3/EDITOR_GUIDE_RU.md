# Как заполнять сайт после обновления 5.3

## Заголовки и обычный текст

Заголовок остаётся **одним полем**. Делить его на начало, выделенную часть и окончание не нужно. Простое форматирование (`<span>`, `<br>`, выделение) допускается в этом же поле. Прежнее выделение и переносы сохраняются. Заголовок не разбит на части и не открывается в редакторе кода.

Описания и основной текст редактируются как обычный текст через визуальный редактор. Вставлять каркас страницы, классы CSS или блоки `<section>` не требуется. Независимые данные, например опыт и стоимость, имеют отдельные поля. Пустые необязательные значения не выводятся.

Для повторяющихся пунктов не создаётся десяток полей «пункт 1», «пункт 2» и т. п. Простые списки вводятся по одному пункту с новой строки, сложные карточки — отдельными записями.

## Блог

Открывайте **Блог → Статьи**. У обычной статьи есть галочка **«Рекомендуемая статья»**. Отметьте одну статью; снимите галочку с прежней. Блок рекомендации автоматически покажет её с тем же адресом. Если отмечено несколько, выводится первая по порядку; если ни одной — карточка рекомендации скрывается, заголовок блога остаётся.

Вкладка рекомендации остаётся представлением общей коллекции: повторно заполнять статью в ней не надо. Главная страница также читает общую коллекцию.

**Категория** выбирается из штатного списка. Переименовывайте и добавляйте категории в **Разработка → Списки → Категории статей**. Названия фильтров берутся оттуда автоматически. Категория без опубликованных статей показана неактивной. Галерея использует отдельный список **«Категории фотографий»**.

Основной текст статьи — обычный визуальный редактор. Если нужны карточки практических советов, откройте **Данные проекта → Практические советы в статьях**: выберите статью, укажите заголовок, текст и при необходимости иконку. Число советов не ограничивается четырьмя. Заголовок всей группы советов находится в обычной статье.

## Специалисты

В карточке специалиста заполняйте только нужные данные:

- Город и формат работы; город можно брать из региона галочкой.
- Опыт, например `8 лет`.
- Кому помогли — **одно поле**, например `Более 300 подростков и семей`.
- Адрес приёма; можно брать из региона галочкой.
- Онлайн-консультации — **одно поле**, например `Онлайн по всей России (Google Meet, Zoom)`.
- Продолжительность и стоимость сеанса.
- Биография в визуальном редакторе и, при необходимости, отдельная цитата.

Если заполнен только опыт, появится только опыт. Пустых строк приёма и пустых разделов биографии, методов и образования не будет. Старые поля с каркасом HTML скрыты; содержимое перенесено автоматически и сохранено в копии обновления.

**Методы** и **образование** — обычные связанные записи в разделе **Данные проекта**. У каждой записи выбирается специалист. У метода — название, описание, необязательная иконка. У образования — учебное заведение/документ, программа, годы и необязательный логотип. На странице специалиста при входе администратором есть ссылки к этим спискам. Порядок меняется штатным порядком объектов Netcat.

В самой карточке остаётся поле **«Вступление к разделу методов»**. Дипломы и сертификаты загружайте в существующее файловое поле специалиста: настоящие сканы сохраняются отдельно от текстовых сведений об образовании.

## Программы, карточки и другие блоки

| Где | Как заполнять |
|---|---|
| Программа: направления и сопровождение | Каждый пункт с новой строки, без `<li>` |
| Достижения основателя | Каждое с новой строки |
| Карточка: пункты списка | Каждый пункт с новой строки; описание отдельно |
| Статические подписи и тексты блока | Настройки соответствующего инфоблока, с понятными подписями |
| FAQ | Вопрос и ответ отдельными полями; опубликованные заполненные пары попадают в JSON-LD |
| Отзывы | Имя, роль, текст и необязательное фото |
| Изображения, иконки, документы | Штатные поля загрузки файлов |
| Контакты, город и доменная привязка | Существующий справочник регионов; заполненные контакты используются и в разметке |

## Текст на странице услуги

В разделах с макетом `service.html` появился инфоблок **«Текст страницы»**. Добавьте запись, введите текст в визуальном редакторе; заголовок необязателен. Секция `text-block` собирается автоматически. Второй H1 рядом с баннером услуги не создаётся. Пока записей нет или они пустые, секция не выводится.

## JSON-LD

Отдельные поля с JSON заполнять не нужно. Разметка строится из опубликованного содержимого: названий, статей, FAQ, услуг, отзывов и региональных контактов. Пустые свойства и выдуманные оценки не добавляются. После изменения данных разметка обновляется вместе со страницей.
