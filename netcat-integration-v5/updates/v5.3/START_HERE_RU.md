# Обновление 5.3 поверх существующего сайта

Подготовлено по актуальным `lifepodr6112026/public_html` и `6112026postroisvo_zhizn.sql.zip`. **Откатывать прошлый патч и переустанавливать сайт не нужно.** Используется новый пакет обновления; старый `zhp-install.php` запускать не надо.

Статус публикации сохраняется. Выключенный сайт останется выключенным до вашей проверки. Смотреть его можно в браузере, где выполнен вход администратора Netcat.

1. Сохраните резервную копию файлов и базы через панель SpaceWeb. Отключите прежний cron установщика, если он ещё работает.
2. Скачайте [lifepodrostka-netcat-v5.3-update.zip](../../../deliverables/lifepodrostka-netcat-v5.3-update.zip). Загрузите и распакуйте **в `public_html` нужного сайта**, с заменой файлов пакета. Рядом с `index.php` появится `zhp-update.php`; внутри существующей темы — `.updates/v5.3`. Не загружайте весь репозиторий или папку бэкапа.
3. Войдите в админку Netcat на этом домене. Откройте `/zhp-update.php`: «Проверить файлы» → «Применить / продолжить». Страница делает короткие запросы и сохраняет прогресс. Если работа прервётся, снова нажмите «Применить / продолжить».
4. Нажмите «Проверить результат». Проверьте статьи, категории, специалистов и услуги. Порядок заполнения описан в [инструкции редактору](EDITOR_GUIDE_RU.md).
5. После проверки удалите корневой `zhp-update.php` и старый `zhp-install.php`, если он остался. Отключите их задания cron. Папки резервных копий `netcat_files/life_teen_v53`, `life_teen_v52` и исходной установки сохраните. Включайте сайт самостоятельно после проверки.

## Запуск через cron SpaceWeb

Вместо браузерной кнопки можно запустить то же обновление через cron. Шаблон команды — подставьте свой абсолютный путь и домен:

```sh
/usr/bin/php7.4 -d short_open_tag=1 /ПОЛНЫЙ/ПУТЬ/public_html/zhp-update.php update --host=ВАШ-ДОМЕН >> /ПУТЬ-ВНЕ-public_html/zhp-update-v53.log 2>&1
```

Расписание: раз в минуту (`*` во всех пяти полях). После сообщения **«Обновление 5.3 применено»** отключите задание. Повторный запуск не создаёт дублей. Для проверки замените `update` на `verify`. Лог храните вне `public_html`. Одновременно запускайте только один способ обновления.

## Сохранение данных и откат

Обновление переносит существующее содержимое в новые поля и связанные записи, сохраняет номера обычных статей и специалистов, их адреса, изображения, документы и региональные настройки. В 19 разделах с макетом услуги добавляется пустой текстовый инфоблок. Пустые разделы меню остаются видимыми, содержимое им не придумывается. Ядро Netcat не меняется.

«Откатить обновление 5.3» возвращает затронутые файлы, записи и настройки к состоянию перед 5.3. Это не откат предыдущего патча. Если после обновления уже изменены затронутые записи или добавлены новые материалы, откат останавливается до изменений, чтобы не затереть работу редактора. Тогда сначала сохраните новые данные и используйте резервную копию осмысленно.
