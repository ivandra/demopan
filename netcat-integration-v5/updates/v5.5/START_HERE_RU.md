# Исправление 5.5 поверх установленного 5.4

Это исправление возвращает обычный список инфоблоков в каждый раздел. **Откатывать 5.4 не нужно.** Данные, фотографии и исправления редактора сохраняются. Сайт останется выключенным до вашей проверки.

1. Сохраните обычную копию файлов и базы через панель хостинга. Если остался cron прежнего установщика, отключите его.
2. Скачайте [lifepodrostka-netcat-v5.5-update.zip](../../../deliverables/lifepodrostka-netcat-v5.5-update.zip). Распакуйте **в `public_html` нужного сайта**, с заменой файлов пакета. Вручную PHP редактировать не надо. Весь репозиторий и папки бэкапов загружать не надо.
3. Войдите администратором Netcat на этом же домене и откройте `/zhp-update.php`: **«Проверить файлы» → «Применить / продолжить»**. Страница делает короткие запросы. Если она закрылась или работа прервалась, откройте её снова и нажмите «Применить / продолжить»: установка продолжится с сохранённого места.
4. Нажмите **«Проверить результат»**. Откройте «Инфоблоки» главной и других разделов: там снова свои списки блоков. Проверьте порядок, отключение, редактирование, создание блока в новом разделе и локальный FAQ по [инструкции редактору](EDITOR_GUIDE_RU.md).
5. После проверки удалите корневой `zhp-update.php` и старый `zhp-install.php`, если он остался. Отключите их cron. Папки **`netcat_files/life_teen_v55` и `life_teen_v54` оставьте**: они содержат настройки источников и резервные копии. Включение сайта остаётся за вами.

[Отчёт по исправлению и прежним пунктам](REPORT_RU.md).

## Запуск через cron вместо браузера

```sh
/usr/bin/php7.4 -d short_open_tag=1 /ПОЛНЫЙ/ПУТЬ/public_html/zhp-update.php update --host=ВАШ-ДОМЕН >> /ПУТЬ-ВНЕ-public_html/zhp-update-v55.log 2>&1
```

Подставьте свои пути и домен. После сообщения **«Обновление 5.5 применено»** отключите задание. Для проверки замените `update` на `verify`. Повторный запуск не создаёт дубли. Не запускайте одновременно браузерную установку и cron.

## Если нужен возврат

«Откатить обновление 5.5» возвращает состояние перед 5.5 — установленный 5.4. При обнаружении последующих изменений материалов или настроек откат останавливается до изменений, чтобы не затереть работу. Для установки этот возврат не требуется.
