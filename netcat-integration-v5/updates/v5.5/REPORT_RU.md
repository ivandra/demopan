# Исправление 5.5: инфоблоки снова управляются в разделах

Перенос самих инфоблоков в 5.4 лишал страницы штатного управления составом. В 5.5 восстановлены **39 размещений с прежними ID, разделами и порядком**. На главной снова 19 обычных инфоблоков. Вывод видимых блоков выполняет Netcat по списку раздела; принудительная карта сборки страниц удалена.

## Как теперь устроено

| Что заполняется | Где хранится и как выводится |
|---|---|
| Состав, порядок, включение блока | Обычный инфоблок в нужном разделе. Его можно добавлять, перемещать, настраивать и отключать штатно. |
| Заголовок и настройки отображения | В этом инфоблоке на странице, независимо от других страниц. Заголовок — одно поле. |
| Повторяемые карточки, иконки и другой общий контент | В выключенном разделе «Общие данные». Альтернативный шаблон читает конкретный источник. |
| Уникальные записи блока | В его разделе при выборе обычного шаблона. Смена режима не удаляет собственные записи. |
| Баннеры, текст страницы, содержимое услуги, контакты | Локальное заполнение в соответствующем разделе. |
| FAQ | Собственные вопросы и ответы каждого инфоблока. Контактный FAQ получил независимые копии ранее показанных вопросов; основной FAQ сохранён. |
| Статьи, специалисты, отзывы, сертификаты | Основные записи остаются в публичных разделах, общие подборки читают их. |

Общие варианты используют `$ignore_cc = 1`, `$ignore_sub = 1` **и ограничение по конкретному инфоблоку-источнику**. Обычные варианты не имеют этих флагов. Для повторного использования подготовлены 16 общих вариантов. Устаревшие общие шаблоны 5.4 удалены после переназначения блоков и сохранены в резервной копии.

Раздел источников не заменяет списки инфоблоков страниц. Служебное скрытое окно консультации остаётся общим элементом интерфейса; если у страницы есть собственный инфоблок окна, его включением управляет этот инфоблок.

## Семь предыдущих пунктов

1. **Город специалиста:** выбор из существующих «Регионов», без ручного поля города. Настройки регионов, контакты и доменные привязки сохранены.
2. **Галерея:** штатное поле Netcat типа 11, четыре группы по категориям, несколько файлов за один выбор. 12 исходных снимков и оригиналы сохранены.
3. **Общее наполнение:** исправлена модель размещений, описанная выше. Менеджер добавляет обычный компонент в раздел и выбирает общий или собственный вариант.
4. **Текст услуги:** в 19 разделах сохранены готовые пустые записи и прямая ссылка редактирования; после заполнения используется `section.text-block`.
5. **Перепроверка:** реальные действия в штатной админке, страницы, формы, сохранность данных, повторный запуск и полный откат.
6. **Методы специалиста:** множественный выбор в карточке, встроенные иконки; общий справочник находится внутри раздела специалистов. Отдельные четыре записи для каждого человека не нужны.
7. **Образование:** строки в карточке специалиста с автоматическими иконками. Старые записи сохранены в выключенном архиве специалистов.

## Остальные согласованные правки

Сохранены плавный FAQ, выбор категорий из списков, рекомендация флажком у обычной статьи, фильтр без видимой надписи «список обновлён», квадратные миниатюры других статей 70 × 70 с `cover`, заполнение полями и условный вывод. Новые локальные карточки и FAQ скрыты, пока в них нет записей. Стандартные иконки локальных карточек встроены в оформление.

JSON-LD сохранена для хлебных крошек, Organization, FAQ страницы и секции, блога и статей, услуг, отзывов и контактов. FAQ-разметка строится только из вопросов, показанных в данном разделе. Локальная проверка выполняется по реально отрисованному HTML. Внешние Schema.org и Google Rich Results недоступны в этом окружении из-за ограничений прокси; успешная проверка этими сервисами не заявляется.

Проверено на изолированной копии Netcat 7.2.0 из предоставленного бэкапа с последовательно установленными 5.3, 5.4 и 5.5, MySQL 5.7.27. Для PHP установлен лимит 64 открытых файлов.

| PHP 7.4.33: заполнение и поведение страниц после браузерной установки | 56 проверок, ошибок нет |
| PHP 7.4.33: браузерная установка с продолжением, права, CSRF, повторный запуск, защита отката | 280 проверок, ошибок нет |
| PHP 8.3.36: установка через CLI, страницы и заполнение | 236 проверок; 15 страниц при 1440, 820 и 390 px — 45 просмотров, ошибок нет |
| PHP 8.3.36: права, CSRF, проверка результата, повторный запуск, защита отката | 19 проверок, ошибок нет |

| Сохранность на обеих версиях PHP | 119 исходных записей, 14 585 исходных файлов, весь справочник регионов, 4 группы и 12 фотографий — без изменений, кроме запланированной смены мест хранения |
| Полный откат в тестовой копии на обеих версиях PHP | Исходные записи, метаданные и все 26 593 исходных файла совпали с состоянием до 5.5 |

Браузерные проверки включают пустые локальные карточки и FAQ, изменение общего источника на двух страницах, независимые заголовки, сохранение собственных записей при смене шаблона, пакетную загрузку трёх фотографий и создание специалиста с документом. Ошибки отдельных PHP-шаблонов Netcat проверяются отдельно от HTTP-статуса страницы. После проверок статус сайта — выключен.

Машиночитаемые результаты — [results.json](results.json). Сценарии находятся в `tests/native-v55`: действия в реальном списке инфоблоков и формах, проверки страниц и сохранности, браузерная установка с продолжением и защищённый откат.

[Установка](START_HERE_RU.md) выполняется **поверх 5.4 без его отката**. Рабочий хостинг автоматически не менялся. Сайт остаётся выключенным, 18 пустых разделов — видимыми и пустыми. [Инструкция редактору](EDITOR_GUIDE_RU.md) описывает добавление общего блока в новый раздел и заполнение собственных данных.
