# Отчёт по обновлению 5.4

Обновление устанавливается **поверх 5.3**, без отката прошлого патча. Использован актуальный бэкап от 6 ноября и воспроизведена установка 5.3; перенос читает данные непосредственно с обновляемого сайта. На рабочем хостинге изменения не выполнялись. Сайт при установке остаётся выключенным до вашей проверки.

## Ответы по семи пунктам

| Пункт | Что изменено и где заполнять |
|---|---|
| 1. Город специалиста | В карточке — выбор готовой записи из существующих «Регионов». Ручные поля города убраны. При соответствующей галочке адрес очного приёма берётся из выбранного региона. Записи регионов и доменные привязки не заменяются. |
| 2. Массовая фотогалерея | В «О проекте → Фотогалерея» — четыре группы по категориям и штатное поле Netcat типа **11**. Можно выбрать несколько файлов за один раз, менять порядок и удалять отдельные фотографии. Все 12 исходных снимков перенесены, оригиналы сохранены. Превью создаёт Netcat с ограничением 340 × 228. Вывод использует `$f_img_tpl`, `%Path%`, `%Preview%` и `$f_img`. |
| 3. Общие блоки | Создан выключенный раздел **«Общие блоки»**. Существующие инфоблоки и записи перенесены с сохранением ID. Одинаковое содержимое объединено через конкретный источник; различающиеся блоки оставлены отдельно. Основные статьи и специалисты остаются в своих разделах. Локальные шаблоны ограничены своим инфоблоком. Общие варианты имеют `$ignore_cc = 1; $ignore_sub = 1;` и обязательное условие по ID источника. Настройки одинакового общего блока также читаются из источника: одно изменение появляется на разных страницах. Верхние баннеры и текст услуги остаются локальными. |
| 4. Текст услуги | В каждом разделе с макетом услуги есть **«Текст страницы услуги — редактируется здесь»** и готовая пустая запись. На странице для администратора есть прямая ссылка её редактирования. После заполнения выводится `<section class="text-block">`, как на главной. Пустая секция посетителю не выводится. Проверены 19 редакторов услуг. |
| 5. Перепроверка | Проверены страницы, реальные формы CMS, массовая загрузка, общие источники, сохранность данных, повторный запуск и возврат к 5.3. Подробности ниже. |
| 6. Методы специалиста | В карточке — множественный выбор галочками. Четыре объекта для каждого человека создавать не нужно. Общие названия и описания редактируются в выключенном инфоблоке **«Методы работы — общий справочник» внутри раздела специалистов**. Полей владельца и загрузки иконки нет. Иконки встроены; переименование стандартного метода сохраняет его иконку. Новый метод получает стандартную встроенную иконку. |
| 7. Образование | Заполняется строками прямо в карточке специалиста: заведение/документ, программа, годы. Добавление и удаление — в этой же форме. Иконки подставляются автоматически. Исходные записи сохранены в выключенном архиве внутри раздела специалистов; редактировать их отдельно больше не требуется. |

Заголовки остаются **одним полем** с допустимым минимальным HTML. Пустые значения и строки не выводятся. В «Данных проекта» остаются советы для статей; методы и образование перенесены к специалистам. 18 пустых разделов меню остаются видимыми и пустыми.

## Что проверено

- Netcat **7.2.0**, MySQL **5.7.27**, PHP **7.4.33** и **8.3.36**. Ограничение открытых файлов у тестового PHP — **64**.
- **15 страниц × 3 ширины**: 1440, 820 и 390 px. Главная, о проекте, блог, три статьи, галерея, FAQ, специалисты, карточка специалиста, контакты, сертификаты, отзывы, пустой раздел и услуга. Нет переполнения по ширине, битых изображений или повторяющихся H1.
- FAQ: промежуточные высоты при открытии, быстрые повторные клики, закрытие, уменьшение движения. Фильтр статей без видимой служебной надписи. Миниатюры других статей — 70 × 70 с `object-fit: cover`.
- Реальные формы Netcat: смена региона и адреса, выбор методов, строки образования с кавычками и `&`, удаление всех строк, создание нового специалиста с документом, редактирование общего справочника.
- Реальная массовая загрузка **трёх фотографий одним сохранением**, создание превью, удаление только выбранного файла, сохранение порядка и фильтр по категории.
- Текст услуги: открытие существующей пустой записи, сохранение через редактор, вывод секции с одним H1.
- Общие блоки: одно изменение настроек на двух страницах; общий шаблон работает без временного контекста и исключает включённую тестовую запись из чужого инфоблока. Локальный шаблон проверен отдельно, без зеркала.
- **96 исходных объектов**: неизменяемые поля сохранены. Проверены контрольные суммы **13 553 исходных файлов** медиа, ядра, админки, библиотек и регионального виджета. Полный справочник регионов совпадает с исходным снимком. Сохранена резервная копия 5.3.
- Полный штатный откат на PHP 7.4 и 8.3: исходные объекты и метаданные восстановлены, контрольные суммы всех **24 812 файлов** совпадают. Автоматические даты кеша разделов не вызывают ложного запрета отката; содержимое и настройки разделов защищены.
- Браузерное обновление короткими запросами с контрольными точками, защита от гостевого запуска и неверного CSRF, закрытые файлы копии, повторный запуск без дублей. Откат после редактирования останавливается до изменения данных.
- JSON-LD повторно проверена по реально отрисованному HTML: **1743 локальные проверки**, включая соответствие FAQ, заголовков и текста статей, связи страниц и абсолютные URL. Внешние validator.schema.org и Google Rich Results в этом окружении недоступны: прокси возвращает CONNECT 403. Успешная проверка этими сервисами не заявляется.

Машиночитаемые результаты: [results.json](results.json). Сценарии повторной проверки: `tests/native-v54`.
