# Как заполнять сайт после 5.4

## Специалист

Откройте **О проекте → Специалисты → Специалисты → нужная карточка**.

- **Город из справочника «Регионы»** — выберите готовый город. Новые города добавляются в существующем разделе «Регионы». При включённом «Очный приём: брать адрес выбранного региона» город и адрес приёма берутся из выбранной записи. Ручного ввода города в карточке больше нет.
- **Методы работы** — отметьте несколько галочек. Четыре отдельных объекта для каждого специалиста создавать не нужно. Иконки подставляются автоматически.
- **Образование** — заполните строки «Учебное заведение / документ», «Специальность / программа», «Годы / год выдачи». Кнопки добавляют и удаляют строки в этой же карточке. HTML и JSON вводить не нужно. Иконки учебного заведения и документа выбираются автоматически.
- **Дипломы и сертификаты** — прежняя штатная множественная загрузка файлов Netcat сохранена.

Пустые поля и полностью пустые строки не выводятся. Существующие три строки образования, включая повторяющуюся запись, перенесены без удаления: ненужную строку можно убрать в карточке самостоятельно.

Общий список методов находится здесь же, в разделе специалистов: **инфоблок «Методы работы — общий справочник»**. Он выключен для прямого вывода. Название и описание метода задаются один раз, варианты выбора в карточках обновляются при открытии формы специалиста. Полей выбора специалиста и загрузки иконки в справочнике нет. Для нового метода используется встроенная стандартная иконка.

Выключенный подраздел «Архив данных до 5.4» хранит прежнее образование и неиспользуемые исходные записи методов. Для текущего заполнения он не нужен. В «Данных проекта» остаются практические советы для статей.

## Фотогалерея

Откройте **О проекте → Фотогалерея → Фотографии — массовая загрузка по категориям**.

Вместо отдельного объекта для каждого снимка здесь группы по типам фотографий. Откройте нужную группу и в поле **«Фотографии — можно выбрать несколько файлов»** выделите сразу несколько изображений. Сохраните объект. Можно менять порядок и удалять файлы штатными средствами Netcat.

Категория выбирается из списка. Исходные 12 фотографий уже перенесены; старые одиночные записи сохранены в выключенном архиве. На сайте используются превью, а при открытии фотографии — оригинал.

## Общие блоки

В дереве сайта появился выключенный раздел **«Общие блоки»**. Он хранит общий контент, который выводится на нужных страницах. Редактируйте текст, настройки и объекты в источнике один раз; изменения появятся во всех местах использования этого источника.

Некоторые строки являются зеркалами источника с другим оформлением. Netcat показывает связь с исходным инфоблоком: редактируйте именно источник. Различающиеся по содержимому блоки сохранены отдельно. Основные списки статей и специалистов остаются в публичных разделах, общие подборки читают их записи.

Для компонентов сохранён локальный шаблон без общего поиска и создан вариант «общий вывод». Общий вариант закреплён за определённым инфоблоком. Не нужно самостоятельно добавлять неограниченные `$ignore_cc = 1; $ignore_sub = 1;`.

Верхний баннер остаётся в своей странице. Заголовки остаются **одним полем**; минимальное форматирование внутри него допустимо.

## Текст услуги

Откройте **нужную страницу услуги → Инфоблоки / Редактирование → «Текст страницы услуги — редактируется здесь»**. Внутри уже есть пустая запись: откройте её и заполните заголовок и текст обычным редактором. Создавать объект вручную не требуется.

В режиме просмотра администратором на самой странице есть ссылка **«Редактировать текст этой страницы услуги»**. Она открывает именно эту запись. На заполненной странице выводится `<section class="text-block">`, как на главной. Пока текст пустой, посетитель не видит пустой секции или служебной ссылки.
