# Проверки чистого патча v5

Проверено на виртуальной копии исходного Netcat **7.2.0**, PHP **8.3.36**,
MariaDB **10.11**, Chromium **153**. Рабочий хостинг не изменялся.

## Полные сценарии через браузер

Каждый сценарий проходит установку, очистку прежних объектов CMS, штатное
редактирование, отправку форм, полное восстановление и повторную установку.

| Исходное состояние | Браузерные проверки | Точный возврат таблиц | Точный возврат файлов |
| --- | --- | --- | --- |
| Исходный сайт и SQL | 75/75 | 133 | 5672 |
| Установленный v4 | 75/75 | 155 | 7148 |
| v3 после штатного отката | 75/75 | 155 | 7167 |

При восстановлении сравниваются все значения всех колонок прикладных таблиц
(Class, Field, Template, Sub_Class, Subdivision, Catalogue и Message-таблиц),
а файлы сверяются по SHA-256. В том числе проверен точный возврат кода с
обратными слешами. Служебная административная сессия поддерживается при
восстановлении таблиц авторизации. Источники снимков не входят в архив.

## Проверка непосредственно в CMS

**125 проверок** зарегистрированных объектов CMS подтвердили:

- В дереве нет прежних «Цен», «Кейсов», sitemap и архивов старого переноса.
- Нет прежних макетов Medelta / lifepodrostka / zhizn_podrostka и компонентов
  `lp_*` / `zhp_*`; региональный компонент 223 сохранён.
- Все восемь макетов проекта проверены по действующим файлам Header,
  Footer, Settings: без поясняющих комментариев и дополнительных оболочек.
- Все компоненты проекта проверены по редактируемым частям.
- 18 запрошенных черновиков не содержат инфоблоков и закрыты от посетителей.
- Остальные разделы с готовым содержимым имеют инфоблоки.
- Массивы `$mobile_menu` / `$h_menu` записаны явно, по принципу Medelta.

В штатных редакторах проверены читаемые отступы, видео с четырьмя полями,
разделение префикса/объекта/суффикса и наследование `%Header` / `%Footer`.
Изменение специалиста, даты статьи, телефона региона и настроек макета
проверено через реальные формы Netcat.

Служебные разделители самого Netcat в Class.html / Template.html сохраняются:
они нужны файловому API. Редактор штатно скрывает их; поясняющих комментариев
в пользовательских полях проекта нет. Служебные макеты самой CMS не удалены.

## Страницы, формы и навигация

Проверены **13 готовых страниц**, **148 локальных ресурсов**, подробные статья/специалист и 9 типов страниц на ширинах 360/768/1440. Smoke: **238 проверок**, ошибок JavaScript интеграции нет.

Проверены контактная форма, подписка, квиз и форма консультации из
предоставленного `popup.html`: записи сохраняются штатным add.php Netcat.
Проверены связанные статьи/специалисты, фильтры и исходный калькулятор.
Отправка внешних писем выключена и не тестировалась.

Для проверки трёх уровней меню на стенде временно включались два пустых
черновика без создания содержимого. После теста их закрытый статус восстановлен
и повторно проверен. Исходное окно консультации открывается и на мобильной
ширине. Запросов на изменение рабочего хостинга не выполнялось.

PHP: **192 файлов** без ошибок синтаксиса; структурная сверка: **359 проверок**. Все классы разметки компонентов и начальных записей есть в предоставленных HTML. Правила основного CSS сохранены.

## Сохранённые особенности исходной вёрстки

В сравнении с оригинальными HTML совпали следующие горизонтальные
переполнения; собственные стили для их исправления не добавлялись:

| Страница | Окно | Оригинал / интеграция |
| --- | --- | --- |
| `/o-nas/spetsialisty/golub-irina-aleksandrovna.html` | 360 | 382 / 382 |
| `/` | 768 | 778 / 778 |
| `/o-nas/foto/` | 768 | 774 / 774 |

На 360 px у специалиста выходит исходная повёрнутая цитата. На 768 px
переполняются исходные главная и галерея. В эталонных HTML есть ошибки
безусловного запуска калькулятора на страницах без него; они записаны
отдельно как `sourceErrors`. В интеграции калькулятор запускается при наличии
блока. Карту, реквизиты и сетевые ссылки нужно проверить в записи региона.
