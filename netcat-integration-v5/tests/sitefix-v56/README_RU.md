# Проверки патча 5.6

Только для изолированной копии сайта после последовательной установки 5.3, 5.4 и 5.5. Сценарии проверяют Docker-адрес и имя тестового контейнера; браузерные запросы ограничены копией. На рабочем хостинге запускать нельзя.

- `qa.mjs`: 18 страниц при 1440/820/390 px, состав и заголовки, четыре этапа пути, отсутствие переполнения, запись текста, пропорции фотографий, клики по специалистам, нижняя навигация статей и исключение выключенных записей, телефон при наборе/вставке/удалении, проверка email, фактическая отправка двух форм и сохранение в Netcat, подстановки SEO/SMM/H1/баннера/текста с двумя наборами региональных значений, сохранность массовой галереи и удаление старого архива. Временные изменения восстанавливаются в `finally`.
- `service-schema.py`: JSON-LD всех 18 подготовленных страниц — названия и описания услуги, канонические URL и хлебные крошки сверяются с видимым содержимым.
- `lifecycle.mjs`: установка через браузер короткими запросами с продолжением, повторное применение без дублей, гостевой запрет и CSRF, защищённые копии, остановка отката после изменений, обычный редактор заголовка, сохранение выключенного статуса сайта.
- `data-check.py`: исходные записи и медиа, справочник регионов, мультифайлы; в режиме отката — точные метаданные и все исходные рабочие файлы. Корневые инструкции и `results.json`, распакованные из ZIP до запуска обновления, исключены из сравнения. 12 записей старого архива считаются запланированным удалением после сверки снимков с массовой галереей.
- `../native-v55/architecture.mjs`: штатные списки инфоблоков, порядок, отключение, создание нового размещения, свои/общие данные и местный FAQ.
- `../native-v55/qa.mjs`: прежние редакторы специалистов, города, методов и образования, документы, пакетная галерея, категории/рекомендации статей, текст услуги и 45 просмотров страниц.
- `../editorial/schema.py`: локальная проверка JSON-LD по HTML; внешние валидаторы ею не заменяются.

Для Node нужны Playwright из `CODEX_PRIMARY_RUNTIME_NODE_MODULES` и путь к Chromium в `NETCAT_CHROMIUM_MODULE`. Переменные: `NETCAT_TEST_HOST`, `NETCAT_REPRO_ADDRESS`, `NETCAT_QA_OUTPUT`, `NETCAT_TEST_SITE`, `NETCAT_REPRO_WEB_CONTAINER` (`demopan-repro-web` или `demopan-repro-web83`). Python использует PyMySQL, `NETCAT_REPRO_DB_ADDRESS` и `NETCAT_QA_BASELINE`. Пути временных материалов — `/tmp/demopan-*`.

`NETCAT_SKIP_GRID=1` запускает поведение без повторения размеров. `NETCAT_BROWSER_APPLY=1` включает браузерную установку с контрольными точками. `NETCAT_CHECK_ROLLBACK=1` включает точную сверку после отката. Базовые хеши таблиц и файлов снимаются до установки; `_qa_files56.php` существует только в тестовой копии и не входит в патч. Проектные PHP-файлы проверяются отдельно, включая раздельные префикс, объект и суффикс Netcat.

Сборка: `python3 netcat-integration-v5/build/sitefix-update-package.py OUTPUT`. Исторические ZIP и генераторы не меняются. SQL, файлы резервной копии сайта, авторизация QA и приватный HTML в пакет не входят.
