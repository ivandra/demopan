# Проверки обновления 5.3

Только для изолированной копии свежих файлов и SQL, не для рабочего хостинга. Скрипты проверяют адрес Docker-контейнера и разрешают только имена тестовых контейнеров. Временные материалы и HTML форм сохраняются в `/tmp/demopan-*`, не публикуются.

- `qa.mjs`: 15 страниц × 1440/820/390, изображения, H1, JSON-LD, анимация FAQ и быстрые клики, уменьшение движения, фильтр статей, квадратные миниатюры; реальные формы редактирования категорий, рекомендации, специалиста, методов, образования, советов и текста услуги, загрузка файлов. Исходные записи возвращаются в `finally`.
- `lifecycle.mjs`: гостевой запрет установщика, CSRF, установка короткими запросами с сохранением прогресса (`NETCAT_BROWSER_APPLY=1`), проверка и повторный запуск, защищённые копии, запрет отката при изменённых данных, сохранение одного поля заголовка с минимальным HTML, гостевой вывод и возврат выключенного статуса сайта.
- `data-check.py`: неизменяемые поля исходных записей, исходные медиа/ядро/регионы, число перенесённых элементов и выключенный статус сайта.
- `schema.py`: JSON-LD из реально отрисованного HTML: типы и связи страниц, абсолютные URL и уникальные ID, соответствие вопросов/ответов видимому FAQ, заголовкам и тексту статей, отсутствие пустых свойств и придуманных рейтингов. Это локальные проверки, а не результат внешнего валидатора.

Переменные: `NETCAT_TEST_HOST`, `NETCAT_REPRO_ADDRESS`, `NETCAT_QA_OUTPUT`, `NETCAT_CHROMIUM_MODULE`; опционально `NETCAT_REPRO_WEB_CONTAINER` (`demopan-repro-web` или `demopan-repro-web83`). Playwright берётся из `CODEX_PRIMARY_RUNTIME_NODE_MODULES`. Для `schema.py` необходим BeautifulSoup. `NETCAT_SKIP_GRID=1` запускает поведение и редактирование без повторения сетки разрешений.

Сборка ZIP: `python3 netcat-integration-v5/build/editorial-update-package.py OUTPUT`. Исторический `build.py` не применяется к модели 5.3; старые полные архивы остаются историческими.
