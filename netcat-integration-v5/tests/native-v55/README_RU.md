# Проверки исправления 5.5

Сценарии предназначены для изолированной копии актуального сайта с установленными 5.3 и 5.4. На рабочем хостинге их запускать нельзя. Тесты сверяют имя и Docker-адрес QA-контейнера, браузер ограничивает запросы локальной копией. HTML форм и временные данные остаются в `/tmp/demopan-*`.

- `architecture.mjs`: реальный `/netcat/admin/index.php#subclass.list(42)` и `mainViewIframe`; 19 обычных блоков главной; сохранение порядка; отключение и включение; создание раздела и добавление компонента через выбор группы, компонента и общего шаблона; отсутствие копий записей; независимые заголовки; изменение общего источника на двух страницах; переход на локальный шаблон, свои записи и встроенная иконка; возврат на общий шаблон с сохранением собственных записей; независимый FAQ контактов и нового раздела, пустые состояния и JSON-LD только показанных вопросов. Целевая проверка штатной админки — PHP 7.4.
- `qa.mjs`: 15 страниц при 1440/820/390 px; изображения, H1, JSON-LD и ошибки PHP-шаблонов; анимация FAQ по кадрам, быстрые клики и уменьшение движения; категории и рекомендация обычной статьи, отсутствие рекомендации и изображения; фильтр без служебной надписи; квадратные миниатюры; выбор города, методы, строки образования, создание специалиста с документом; загрузка трёх фото одним сохранением, удаление и порядок; редактор текста услуги. Исходные значения восстанавливаются в `finally`.
- `lifecycle.mjs`: гостевой запрет, CSRF, установка короткими запросами с контрольными точками и продолжением, повторный запуск без дублей, защищённые копии, запрет отката после изменения материалов или настроек раздела, сохранение одного поля заголовка и выключенного статуса.
- `data-check.py`: исходные объекты и неизменяемые поля, полный справочник регионов, оригинальные файлы и фотографии. При `NETCAT_CHECK_ROLLBACK=1` — точное сравнение исходных записей, метаданных и всех файлов после отката.
- `../editorial/schema.py`: локальная семантическая проверка JSON-LD по реально отрисованному HTML. Внешние валидаторы ею не заменяются.

Переменные: `NETCAT_TEST_HOST`, `NETCAT_REPRO_ADDRESS`, `NETCAT_QA_OUTPUT`, `NETCAT_CHROMIUM_MODULE`, `NETCAT_TEST_SITE`; для Python — `NETCAT_QA_BASELINE`, `NETCAT_REPRO_DB_ADDRESS`. `NETCAT_REPRO_WEB_CONTAINER`: `demopan-repro-web` или `demopan-repro-web83`. Playwright берётся из `CODEX_PRIMARY_RUNTIME_NODE_MODULES`, Python использует PyMySQL и BeautifulSoup.

`NETCAT_SKIP_GRID=1` пропускает повтор размеров; `NETCAT_BROWSER_APPLY=1` включает браузерную установку. Для нативного выбора шаблона ожидается завершение штатных AJAX-запросов формы. Файловые префиксы, объекты и суффиксы Netcat проверяются как отдельные PHP-файлы.

Сборка: `python3 netcat-integration-v5/build/section-update-package.py OUTPUT`. Исторические архивы и старые генераторы не изменяются. SQL, копии сайта и вспомогательная авторизация в пакет не входят.
