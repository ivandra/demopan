# Проверки обновления 5.4

Сценарии предназначены только для изолированной копии Netcat с установленным 5.3. Не запускать на рабочем хостинге. Тесты разрешают только заданные имена QA-контейнеров и сверяют их Docker-адрес; браузер блокирует запросы за пределы копии. Временные материалы и приватные HTML форм хранятся в `/tmp/demopan-*`.

- `qa.mjs`: 15 страниц при 1440/820/390 px, изображения, H1 и JSON-LD; FAQ с замерами кадров, быстрые клики и уменьшение движения; фильтры статей и галереи; реальные формы города, методов и образования; создание специалиста с документом; загрузка трёх изображений одним сохранением, удаление и порядок; готовый редактор текста услуги; настройки общего блока в настоящем модальном окне админки; точный общий источник и локальный шаблон без зеркала. Тестовые записи и исходные значения возвращаются в `finally`.
- `lifecycle.mjs`: гостевой запрет, CSRF, браузерное обновление короткими запросами, продолжение и повторный запуск, защищённые копии, запрет отката при изменениях текста или настроек раздела, одно поле заголовка с минимальным HTML, гостевой вывод и сохранение выключенного статуса.
- `data-check.py`: 96 исходных объектов, неизменяемые поля и даты, полный справочник регионов, исходные медиа/ядро/библиотеки/региональный виджет, четыре группы и 12 перенесённых фотографий. При `NETCAT_CHECK_ROLLBACK=1` — точное сравнение исходных объектов, метаданных и 24 812 файлов после отката.
- Для проверки JSON-LD применяется `../editorial/schema.py` к HTML, сохранённому текущим прогоном. Это локальная проверка, а не результат внешних валидаторов.

Переменные: `NETCAT_TEST_HOST`, `NETCAT_REPRO_ADDRESS`, `NETCAT_QA_OUTPUT`, `NETCAT_CHROMIUM_MODULE`, `NETCAT_TEST_SITE`; для Python также `NETCAT_QA_BASELINE`, `NETCAT_REPRO_DB_ADDRESS`. `NETCAT_REPRO_WEB_CONTAINER` — `demopan-repro-web` или `demopan-repro-web83`. Playwright берётся из `CODEX_PRIMARY_RUNTIME_NODE_MODULES`. Python требует PyMySQL и BeautifulSoup.

`NETCAT_SKIP_GRID=1` пропускает повторный прогон размеров. `NETCAT_BROWSER_APPLY=1` включает установку через браузер. Исходный контрольный снимок создаётся перед обновлением 5.4 после восстановления актуального SQL и установки исторического пакета 5.3.

Сборка: `python3 netcat-integration-v5/build/native-update-package.py OUTPUT`. Проверялся MySQL 5.7.27 и ограничение открытых файлов 64. SQL, копии сайта и вспомогательная авторизация в пакет не входят.
