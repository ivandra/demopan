## Что переработано

Код с отступами, без поясняющих комментариев и дополнительных классов
оболочек. Компоненты разделены на префикс, объект и суффикс по контейнерам
исходной вёрстки. Общие постоянные блоки находятся целиком в префиксе и не
требуют заполнения объектов. Контакты и ссылки берутся из исходных регионов
№223 / №57. Общий подвал наследуется через `%Footer`; год динамический.
Статьи и специалисты используют общие записи для разных вариантов вывода.

## Установка на shared-хостинг

1. Сделайте резервную копию файлов и базы данных сайта.
2. Загрузите **содержимое `UPLOAD_TO_ROOT`** в корень сайта рядом с `vars.inc.php`.
3. Войдите в админку Netcat администратором на том же домене.
4. Откройте `https://dev.lifepodrostka.ru/zhp-install.php`.
5. Нажмите «Проверить файлы» → «Установить / продолжить» →
   «Включить новый сайт» → «Проверить установку».
6. После проверки удалите с хостинга `zhp-install.php`.
   Каталоги шаблонов и резервные данные в `netcat_files` оставьте.

Подходит для исходного сайта, обновления v3 и установки после штатного
отката v3. На хостинг переносится только `UPLOAD_TO_ROOT`; `DEVELOPMENT`
содержит исходники сборки и проверки. Контрольные суммы архивов —
[SHA256SUMS.txt](SHA256SUMS.txt). Предыдущий v3 сохранён в этой папке.
