Скачайте **полный архив** либо **обе части**. Части — самостоятельные ZIP:
распакуйте их в одну папку. Объединять их в один файл не нужно.
После распаковки двух частей набор файлов побайтно совпадает с полным архивом.

Если GitHub показывает страницу бинарного файла, нажмите **Download raw file**.

## Установка на shared-хостинг

1. Сделайте резервную копию файлов и базы данных сайта.
2. Загрузите **содержимое `UPLOAD_TO_ROOT`** в корень сайта рядом с `vars.inc.php`.
3. Войдите в админку Netcat администратором на том же домене.
4. Откройте `https://dev.lifepodrostka.ru/zhp-install.php`.
5. Нажмите «Проверить файлы» → «Установить / продолжить» →
   «Включить новый сайт» → «Проверить установку».
6. После проверки сайта удалите с хостинга `zhp-install.php`.
   Каталоги шаблонов и резервные копии в `netcat_files` оставьте.

Для приложенного пакета v2 предварительный сброс не нужен.
На хостинг загружается только содержимое `UPLOAD_TO_ROOT`;
папка `DEVELOPMENT` предназначена для разработки и тестирования.

Внутри архива находятся `START_HERE_RU.md`, `TEST_REPORT_RU.md`,
исходники сборки и результаты проверок. Контрольные суммы трёх ZIP —
в [SHA256SUMS.txt](SHA256SUMS.txt).

Это тот же подготовленный пакет v3: содержимое сайта не изменено при
размещении в Git. На хостинг изменения не устанавливались.
