# «Жизнь подростка» — обновление 5.3

Для сайта из свежего бэкапа `lifepodr6112026` и `6112026postroisvo_zhizn.sql.zip` используйте **обновление 5.3 поверх предыдущего патча**. Откатывать прошлый патч и переустанавливать сайт не нужно.

- **[Скачать ZIP для распаковки в public_html](https://raw.githubusercontent.com/ivandra/demopan/main/deliverables/lifepodrostka-netcat-v5.3-update.zip)**.
- **[Установка через браузер или cron SpaceWeb](../netcat-integration-v5/updates/v5.3/START_HERE_RU.md)**.
- **[Инструкция редактору](../netcat-integration-v5/updates/v5.3/EDITOR_GUIDE_RU.md)**.
- [Ответы по девяти пунктам](../netcat-integration-v5/updates/v5.3/ANSWERS_RU.md).
- [Проверки и ограничения внешних валидаторов](../netcat-integration-v5/updates/v5.3/QA_RU.md).
- [Контрольные суммы](SHA256SUMS.txt).

Пакет исправляет FAQ, категории, рекомендацию статьи, фильтры и миниатюры; добавляет текстовый инфоблок услуг и JSON-LD. Данные специалистов и повторяющиеся карточки заполняются обычными полями и связанными записями. Заголовок остаётся одним полем с минимальным форматированием.

Распакуйте ZIP рядом с `index.php`, войдите администратором Netcat и откройте `/zhp-update.php`: «Проверить файлы» → «Применить / продолжить» → «Проверить результат». Сначала сохраните копию файлов и базы в панели хостинга. Статус публикации сохраняется: выключенный сайт останется выключенным до вашей проверки. Пустые разделы меню остаются видимыми и пустыми.

## Исторические архивы

Архивы v3–v5.2 сохранены без изменений. [Обновление 5.2](../netcat-integration-v5/updates/v5.2/START_HERE_RU.md) относится к предыдущим исправлениям по `problem1.txt`. Старые полные архивы содержат установщик с очисткой сайта; для текущего обновления нужен именно `lifepodrostka-netcat-v5.3-update.zip`. Не запускайте заново `zhp-install.php` и не загружайте весь репозиторий на хостинг.
