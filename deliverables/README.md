# «Жизнь подростка» — обновление 5.4

Для сайта с установленным **5.3** используйте **обновление 5.4 поверх него**. Откатывать предыдущий патч и переустанавливать сайт не нужно. Актуальный бэкап от 6 ноября уже учтён; если после 5.3 материалы не менялись, дополнительный бэкап для подготовки не требуется.

- **[Скачать ZIP для распаковки в public_html](https://raw.githubusercontent.com/ivandra/demopan/main/deliverables/lifepodrostka-netcat-v5.4-update.zip)**.
- **[Установка через браузер или cron](../netcat-integration-v5/updates/v5.4/START_HERE_RU.md)**.
- **[Как заполнять карточки и общие блоки](../netcat-integration-v5/updates/v5.4/EDITOR_GUIDE_RU.md)**.
- **[Отчёт по всем семи пунктам и проверкам](../netcat-integration-v5/updates/v5.4/REPORT_RU.md)**.
- [Машиночитаемые результаты](../netcat-integration-v5/updates/v5.4/results.json).
- [Контрольные суммы архивов](SHA256SUMS.txt).

Город специалиста выбирается из «Регионов»; методы — галочками, образование заполняется строками внутри карточки. Галерея использует штатную массовую загрузку Netcat. Общие блоки заполняются в выключенном разделе и выводятся из конкретных источников. В услугах есть готовая запись для текстового блока и прямая ссылка редактирования. Заголовок остаётся одним полем.

Распакуйте ZIP рядом с `index.php`, войдите администратором и откройте `/zhp-update.php`: «Проверить файлы» → «Применить / продолжить» → «Проверить результат». Перед установкой сохраните обычную резервную копию файлов и базы через панель хостинга. Выключенный сайт останется выключенным до вашей проверки. Пустые разделы меню остаются видимыми и пустыми.

После установки удалите `zhp-update.php` и отключите его cron. Папку `netcat_files/life_teen_v54` **оставьте**: она содержит действующую карту общих блоков и резервную копию.

## Исторические архивы

Архивы v3–v5.3 сохранены без изменений. Для сайта до 5.3 сначала примените [обновление 5.3](../netcat-integration-v5/updates/v5.3/START_HERE_RU.md). Старые полные архивы содержат установщик с очисткой сайта; для текущей задачи нужен именно `lifepodrostka-netcat-v5.4-update.zip`. Не запускайте заново `zhp-install.php` и не загружайте весь репозиторий на хостинг.
