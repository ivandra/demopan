# «Жизнь подростка» — обновление 5.2

Для текущего сайта из `zhizn111` и свежей базы используйте **обновление 5.2**:

- **[Скачать ZIP для распаковки в public_html](https://raw.githubusercontent.com/ivandra/demopan/main/deliverables/lifepodrostka-netcat-v5.2-update.zip)**.
- **[Как применить через браузер или cron SpaceWeb](../netcat-integration-v5/updates/v5.2/START_HERE_RU.md)**.
- **[Ответы на все 22 пункта problem1.txt](../netcat-integration-v5/updates/v5.2/ANSWERS_RU.md)**.
- [Результаты проверок](../netcat-integration-v5/updates/v5.2/QA_RU.md).
- [Контрольные суммы](SHA256SUMS.txt).

Это небольшой пакет исправлений для уже установленного сайта. Он обновляет оформление и компоненты, переводит специализации в штатный список Netcat, добавляет загрузку дипломов, показывает пустые разделы в меню и сохраняет текущие материалы. Выключенный сайт остаётся выключенным до вашей проверки. Новых текстов для пустых разделов и функций из списка предложений не добавляется.

Распакуйте ZIP рядом с `index.php`, войдите администратором Netcat и откройте `/zhp-update.php`: «Проверить файлы» → «Применить / продолжить» → «Проверить результат». Есть запуск через cron. Не запускайте повторную установку или очистку через `zhp-install.php`. Сначала сохраните обычную копию сайта и базы в панели хостинга.

## Исторические архивы

Версии v3–v5.1.1 сохранены в этой папке без изменений. Они относятся к прежним установкам и содержат установщик с очисткой старого сайта. Для исправлений по `problem1.txt` нужен именно `lifepodrostka-netcat-v5.2-update.zip`, а не старые полные архивы или весь репозиторий.
