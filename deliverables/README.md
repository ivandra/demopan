## Что делает патч

После полной резервной копии удаляет из CMS старые разделы, инфоблоки,
макеты Medelta и предыдущих переносов, старые компоненты `lp_*` / `zhp_*`.
В рабочем дереве нет прежних «Цен», «Кейсов», sitemap и архивных разделов.
Регионы остаются существующими: №223 / №57.

Готовое наполнение — только из предоставленных материалов. **18 разделов
без собственного HTML оставлены пустыми отключёнными черновиками**, как
вы попросили. Исходное окно консультации из `popup.html` подключено к Netcat.
Навигация задана явными массивами, код отформатирован, лишних обёрток и
поясняющих комментариев в макетах проекта нет.

## Установка на shared-хостинг

1. Сохраните резервную копию файлов и БД в панели хостинга.
2. Загрузите **содержимое `UPLOAD_TO_ROOT`** в корень сайта рядом с `vars.inc.php`.
3. Войдите администратором в Netcat на том же домене.
4. Откройте `https://dev.lifepodrostka.ru/zhp-install.php`.
5. Выполните «Проверить файлы» → «Установить / продолжить» →
   **«Включить и очистить прежний сайт»** → «Проверить установку».
6. После проверки удалите `zhp-install.php`; резервную папку
   `netcat_files/life_teen_v5` оставьте.

SSH и ручной импорт SQL не нужны. Резервная копия и очистка выполняются
короткими возобновляемыми запросами через браузер. Восстановление и
повторная установка проверены для исходного сайта, v4 и отката v3.
На хостинг переносится только `UPLOAD_TO_ROOT`.

Предыдущие архивы сохранены в этой папке для истории. Для новой установки
используйте v5.
