# «Жизнь подростка» — исправление 5.5

Для сайта с установленным **5.4** используйте **исправление 5.5 поверх него**. Откатывать предыдущий патч и переустанавливать сайт не нужно. Исправление возвращает обычные списки инфоблоков в каждый раздел: порядок, редактирование, включение и отключение снова управляются штатно.

- **[Скачать ZIP для распаковки в public_html](lifepodrostka-netcat-v5.5-update.zip?raw=true)**.
- **[Установка через браузер или cron](../netcat-integration-v5/updates/v5.5/START_HERE_RU.md)**.
- **[Как выбирать свои или общие данные](../netcat-integration-v5/updates/v5.5/EDITOR_GUIDE_RU.md)**.
- **[Отчёт по прежним пунктам и проверкам](../netcat-integration-v5/updates/v5.5/REPORT_RU.md)**.
- [Машиночитаемые результаты](../netcat-integration-v5/updates/v5.5/results.json).
- [Контрольные суммы архивов](SHA256SUMS.txt).

Общий раздел хранит только повторяемые данные. У инфоблока на странице можно выбрать обычный шаблон со своими записями или вариант «— общие данные» с конкретным источником. Заголовок и настройки остаются местными; FAQ, баннеры и текст услуг заполняются в своих разделах. Выбор города из «Регионов», методы галочками, образование внутри карточки, массовая галерея и JSON-LD сохранены.

Распакуйте ZIP рядом с `index.php`, войдите администратором и откройте `/zhp-update.php`: «Проверить файлы» → «Применить / продолжить» → «Проверить результат». Перед установкой сохраните обычную резервную копию файлов и базы через панель хостинга. Выключенный сайт останется выключенным до вашей проверки. Пустые разделы меню остаются видимыми и пустыми.

После установки удалите `zhp-update.php` и отключите его cron. Папки `netcat_files/life_teen_v55` и `life_teen_v54` **оставьте**: они содержат настройки источников и резервные копии.

## Исторические архивы

Архивы v3–v5.4 сохранены без изменений. Для сайта до 5.3 сначала примените [обновление 5.3](../netcat-integration-v5/updates/v5.3/START_HERE_RU.md), затем 5.4 и это исправление. Версия 5.4 оставлена как промежуточная зависимость; исправление её размещений входит в 5.5. Старые полные архивы содержат установщик с очисткой сайта; для текущего сайта после 5.4 нужен именно `lifepodrostka-netcat-v5.5-update.zip`. Не запускайте заново `zhp-install.php` и не загружайте весь репозиторий на хостинг.
