# Фавиконки «Жизнь подростка»

Знак взят из исходного векторного логотипа проекта, без надписи. Круг и основание дерева сохранены целиком. Фон — цвет сайта `#FBF6F0`, основной тёмный цвет — `#001F45`.

## Установка

1. Распакуйте файлы архива в корень нужного сайта — `public_html`, рядом с `index.php`.
2. Вставьте содержимое `head.html` внутрь `<head>` макета сайта.
3. В текущем макете Netcat разместите этот блок после `<?= project_meta_tags() ?>`. Сам вызов `project_meta_tags()` оставьте: он выводит SEO/SMM-метатеги.
4. Если в настройках сайта Netcat задан старый Favicon, замените его файлом `favicon.ico` из набора или очистите это поле. Старые вручную вставленные ссылки на иконки замените новым блоком.
5. Обновите страницу с очисткой кэша браузера. Иконка вкладки может кэшироваться отдельно от самой страницы.

Установщик патча и cron для этого набора не нужны. Код находится в `head.html`, манифест — в `site.webmanifest`. Все пути рассчитаны на размещение файлов в корне домена и подходят как для dev-домена, так и для основного сайта.

## Состав

| Файлы | Размеры и назначение |
|---|---|
| `favicon.ico` | В одном файле: 16, 24, 32, 48, 64, 128 и 256 px |
| `favicon.svg` | Цветной векторный знак, масштабируется без потери чёткости |
| `favicon-…x….png` | 16, 24, 32, 48, 64, 96, 128, 256, 512 и 1024 px |
| `apple-touch-icon.png` | 180 × 180 px для Apple |
| `apple-touch-icon-…x….png` | Дополнительно 120, 152 и 167 px |
| `android-chrome-…x….png` | 192 и 512 px |
| `android-chrome-maskable-…x….png` | 192 и 512 px с отступами для круглых и других масок Android |
| `safari-pinned-tab.svg` | Монохромный трафарет для закреплённых вкладок Safari; цвет задаётся в `head.html` |
| `mstile-…x….png`, `browserconfig.xml` | Плитки Windows 150 и 310 px |
| `site.webmanifest` | Название, цвета, пути и размеры иконок, отдельные обычные и maskable-версии |

PNG имеют непрозрачный светлый фон. У Android maskable всё содержимое знака помещается в центральную безопасную окружность диаметром 80% изображения.
