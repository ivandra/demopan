# «Жизнь подростка» — Netcat v4

Разметка из `zhizn-podrostka` разложена по штатным компонентам и файловым
макетам Netcat 7.2.0. В CMS сохраняется читаемый код с отступами. Декоративные
элементы и постоянные подписи остаются в шаблонах; данные записей — в полях.

## Установка на shared-хостинг

1. Сохраните резервную копию файлов и БД.
2. Загрузите **содержимое `UPLOAD_TO_ROOT`** в корень сайта, рядом с `vars.inc.php`.
3. Войдите администратором в Netcat на том же домене.
4. Откройте `https://dev.lifepodrostka.ru/zhp-install.php`.
5. Последовательно нажмите «Проверить файлы», «Установить / продолжить»,
   «Включить новый сайт», «Проверить установку».
6. Проверьте страницы сайта и удалите с хостинга `zhp-install.php`.

SSH, Composer и ручной импорт SQL на хостинге не нужны. Установщик выполняет
работу небольшими возобновляемыми шагами через браузер. Не удаляйте каталог
`netcat_files/zhizn_podrostka`: там состояние установки и резервные данные.

Пакет рассчитан на приложенный исходный сайт, v3 и установку после отката
v3 штатной кнопкой установщика. Если восстановлены полные исходные файлы и БД,
это чистая установка. При частичном ручном восстановлении файлов/БД сначала
проверьте их согласованность. Исходный компонент регионов №223 и инфоблок №57
должны существовать; установщик проверяет это до их использования.

## Как заполнять

- «ПОЗНАКОМЬТЕСЬ С НАМИ БЛИЖЕ»: четыре поля — заголовок, описание, видео,
  обложка. Открывающие `section`/`wrap` находятся в префиксе, содержимое —
  в объекте, закрывающие теги — в суффиксе.
- Группа родителей, способы связи, соцсети, подписка и калькулятор выводятся
  целиком из префикса. Создавать объекты для них не нужно. Постоянный текст
  меняется в коде компонента, ссылки берутся из региональных данных.
- Статьи и специалисты заполняются один раз. Списки, слайдеры, команда,
  рекомендации и подробные страницы используют эти же записи.
- Статья: заголовок, анонс, цельный текст в визуальном редакторе, картинка,
  дата, время чтения, категория. Текст не разбит на десятки мелких полей.
- Текстовый блок: одно поле визуального редактора.
- Контакты, соцсети, MAX, часы и карта — существующий раздел «Регионы».
  Шорткоды `[phone]`, `[email]`, `[city]`, `[address]`, `[mapcode]` выбирают
  запись по домену. Перед запуском заполните отсутствующие региональные данные.
- Диапазоны калькулятора — шесть настроек инфоблока.
- Общие шапка/подвал — в родительском макете. Дочерние наследуют `%Header`
  и `%Footer`. Год берётся из текущей даты PHP.

В новой установке 22 базовых компонента, 24 шаблона компонентов и 74 поля,
включая служебные поля заявок. Региональный компонент переиспользуется.
При обновлении прежние значения не удаляются: лишние поля v3 скрываются
из формы заполнения. Неиспользуемые прежние макеты и записи сохраняются.

## Страницы для проверки

- Главная: `/`
- О проекте: `/o-nas/`
- Список статей: `/blog/`
- Статья: `/blog/kak-spravlyatsya-s-trevogoy-pered-ekzamenami.html`
- Специалисты: `/o-nas/spetsialisty/`
- Специалист: `/o-nas/spetsialisty/golub-irina-aleksandrovna.html`
- Галерея: `/o-nas/foto/`
- Контакты: `/kontakty/`

Некоторые пункты меню не имеют отдельного исходного HTML. Их текстовые
разделы оставлены для заполнения через CMS. Новые материалы для них не
сочинялись. Вёрсточный текстовый пример на главной сохранён из `index.html`.

Заявки и подписки сохраняются в Netcat. Доставка писем по умолчанию выключена;
параметры берутся из существующих регионов. Отправка реальных писем в тестах
не выполнялась. Снимите настройку `noindex` общего макета перед рабочим запуском.

Папка `DEVELOPMENT` на хостинг не загружается. Состав полей и инфоблоков —
`docs/COMPONENTS_AND_PAGES.md`, устройство — `docs/ARCHITECTURE_RU.md`,
воспроизведение проверок — `docs/BUILD_RU.md`.
