# Проверки Netcat v4

Проверено на изолированной копии пользовательского сайта Netcat **7.2.0**:
PHP **8.3.36**, MariaDB **10.11**, Chromium **153**. Рабочий хостинг не изменялся.

## Установка и сохранность данных

| Сценарий | Проверки браузера | Проверка записей до редактирования |
| --- | --- | --- |
| Исходные файлы и SQL → v4 | 68 / 68 | Исходные записи 127 таблиц сохранены |
| Опубликованный v3 → v4 | 68 / 68 | Исходные записи 149 таблиц сохранены |
| v3 → штатный откат → v4 | 68 / 68 | Исходные записи 149 таблиц сохранены |

Проверены повторная установка, откат и повторная активация; повреждённый
загружаемый файл отклоняется до изменения настроек сайта; без прав
администратора установщик возвращает 403. Старые записи и физические поля
не удаляются. Сохранность проверяется по исходным идентификаторам до
намеренного редактирования; добавление новой записи текстового блока
главной допускается. Внесённое до обновления редакторское изменение статьи
сохраняется. После правки региона штатная форма Netcat нормализует некоторые
пустые необязательные значения NULL в пустые строки; это учтено отдельно
от проверки сохранности при установке.

## Реальные редакторы и работа сайта

- В редакторе компонента видео проверены форматирование и раздельные
  префикс, объект, суффикс; у компонента четыре поля.
- В редакторе общего макета проверены читаемый Header, отсутствие
  добавленных оболочек/комментариев; дочерний макет наследует `%Header`
  и `%Footer`.
- Общие статичные блоки видны без объектов и полей заполнения.
- Изменение ФИО и должности в штатной форме меняет общие представления
  специалиста. Изменение даты статьи меняет рекомендуемую карточку.
- Телефон меняется в исходном компоненте регионов №223 / инфоблоке №57.
  Второй домен показывает собственную региональную запись.
- Подробная статья получает настройки макета своего раздела; связанные
  статьи и специалисты берутся из общих записей, текущая запись исключена.
- Обе подробные страницы выводят общую исходную подписку ровно один раз.
- Контактная форма, подписка и квиз проходят отправку без авторизации;
  в каждой проверке сохраняются три записи Netcat.
- Работают мобильное меню, подменю, фильтр специалистов, исходные ползунки
  калькулятора и ссылки на подробные страницы; якоря меню имеют цели.
- Год в подвале берётся из даты PHP.

Проверены **34 публичные страницы**, **144 локальных ресурса** (все 200), подробные страницы и 9 типов страниц на ширинах 360/768/1440. Браузерный smoke: **250 проверок**, ошибок JavaScript в интеграции нет.

Проверка PHP: **180 файлов**, ошибок синтаксиса и поясняющих PHP-комментариев нет. Структурная сверка: **348 проверок**; все классы разметки есть в предоставленных HTML, правила CSS совпадают с оригиналом. Адреса шрифтов заменены локальными копиями; исходный `common.js` сохранён.

## Особенности исходной вёрстки

При сравнении браузером зафиксированы одинаковые переполнения исходного
HTML и интеграции. В соответствии с требованием сохранить вёрстку CSS не
изменялся для их устранения:

| Страница | Ширина окна | Ширина исходника и интеграции |
| --- | --- | --- |
| `/o-nas/spetsialisty/golub-irina-aleksandrovna.html` | 360 | 382 / 382 |
| `/` | 768 | 778 / 778 |
| `/o-nas/foto/` | 768 | 774 / 774 |

На 360 px у специалиста выходит за окно исходная повёрнутая цитата.
На 768 px переполняются исходные главная и галерея. В эталонных HTML также
есть безусловный код калькулятора на страницах без калькулятора; его ошибки
отдельно записаны в `smoke-results.json/sourceErrors`. В интеграции запуск
калькулятора ограничен наличием блока.

Стенд проверяет функциональность в Chromium, не все браузеры/версии PHP
shared-хостингов. Отправка внешних писем не включалась; заявки проверены
по сохранению в Netcat. Карта и ссылки MAX/соцсетей требуют заполненных
полей региона. Страницы без отдельного предоставленного HTML оставлены
для заполнения через CMS. Уровни заголовков исходного HTML сохранены,
включая вёрсточный пример в текстовом блоке главной.
