# Для разработчика

Установочный пакет содержит сгенерированные штатные файлы компонентов в `netcat_template/template/zhizn_podrostka/.install/components`. После установки Netcat хранит рабочие копии в обычном `netcat_template/class/<keyword>/`.

В `DEVELOPMENT/build` находятся воспроизводимые исходники сборки, явные схемы полей, исходные HTML-макеты и смысловые данные. Эти Python-скрипты нужны для разработки и не загружаются на хостинг.

Для воспроизведения создайте рабочую папку `native-redo`, скопируйте в неё `DEVELOPMENT/build`, а содержимое `UPLOAD_TO_ROOT` — в `native-redo/files`. Из родительской папки выполните `python native-redo/build/native.py`, затем `python native-redo/build/installer.py`. Требуется Python с `beautifulsoup4`; активы берутся из скопированного готового пакета. После изменения клиентского JS заново выполните `installer.py`, чтобы обновить контрольные суммы.

Интеграционные сценарии в `DEVELOPMENT/tests` рассчитаны на отдельную временную копию исходного сайта и импорт предоставленного SQL-дампа. Для них также нужны PHP с расширениями Netcat, MariaDB, PyMySQL, Node, Playwright и Chromium. Адреса и пути среды тестов находятся в `harness.py`; тестовые PHP-точки создаются только внутри временной копии и не включены в `UPLOAD_TO_ROOT`.

Сгенерированные HTML-шаблоны следует редактировать средствами Netcat или в их штатных файловых каталогах. Сборщик не является частью обработки HTTP-запросов сайта.
